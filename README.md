# Sample DJ releases

Downloads for Sample DJ, a macOS app (Apple silicon, macOS 14+) that digs forgotten samples out of
your drives and builds key- and tempo-locked song starters.

Get the latest `Sample-DJ-<version>.zip` from [Releases](../../releases/latest), unzip it and move
`Sample DJ.app` to Applications. The app isn't notarized, so the first time, right-click it and
choose Open. After that it updates itself: an Update button appears when a new version is out.

`latest.json` on each release is what the app reads to find updates.
